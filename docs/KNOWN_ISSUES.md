# 已知问题

## shutdown 缺失时的关闭预览

记录于 2026-08-26，暂不在本轮修复。

当定义包含 `startup`、但没有定义 `shutdown` 时，模组行为应当反演 startup 作为关闭动画。目前 Blender 的“关闭过渡”和“完整序列”预览在部分此类定义中不会播放反演动画。该问题只影响 Blender 预览，不会在导出时生成或改写 `shutdown`，也不会改变资源包在模组内的行为。

## Cycles 中的显式 Ring 内外表面

Halo 的 Ring 在指定独立 `inner_texture` 时使用同半径、反向绕序的两层表面。Cycles 不可靠地遵循该场景所需的材质背面剔除，因此可能同时显示两层共面材质。0.1.15 起请使用“动画预览 → 启用 EEVEE 一致性预览”；EEVEE 的抖动透明与背面剔除是当前保证的视觉验收路径。
