# Halo Pack Editor

面向 Halo Minecraft 模组资源包的 Blender 5.2 LTS 扩展，可新建、导入、编辑、动画预览并导出 ZIP/文件夹资源包。界面使用简体中文，JSON 字段和 Minecraft 资源 ID 保留英文。

导出时会保证 `pack.mcmeta` 同时包含 `pack_format` 和非空 `description`；缺失描述自动补为 `Halo Pack Editor export`，已有描述与未知字段不会被覆盖。

安装后把鼠标移到 3D 视图并按 `N` 打开右侧栏，再点击右侧竖排的“Halo 光环”标签。先从“项目 / 资源包”导入 ZIP 或文件夹，再通过中文界面的“大纲视图”（默认右上角对象树）和 3D 视图右侧栏编辑树、图元、贴图及动画。“树形编辑”面板始终可见；选择一个组后，可按可读组名选择新父级或移回光环根，无需填写 UUID，循环父级会自动排除。组或图元可在当前父级创建独立副本；图元也可迁移到目标父级下自动创建的属性副本组，原组的其他内容不受影响。组移动和图元迁移均可通过默认全选的复选框决定携带哪些组属性。Definition ID 可直接重命名，当前选择、对象树、原始 JSON 与导出 ID 会同步更新。光环属性可编辑全部 `damping` 跟踪参数和角动量开关；阻尼系数越接近 1，越快贴近目标，阻尼运动暂不在 Blender 中模拟。Ring 的外侧与内侧 PNG 可分别导入；清空内侧纹理后按模组默认行为使用外侧纹理。“动画预览”支持 EEVEE 抖动透明及 Cycles 单层双面 Ring；发光表现为自身全亮，不再参与 Cycles 间接照明。静态 JSON 变换由面板的粗调/细调控件管理，受管理对象的原生 G/R/S 会锁定。Halo JSON 的位置、旋转和缩放属于部件组，因此选中图元时会编辑其所属组，同组图元共享变换。startup/shutdown 可按组 ID 图形化管理段、缓动、时间以及各通道的 `from`/`to`、独立时间/缓动和 rotation `degrees`。玩家头部预览中的光环根动画在头部锚点局部坐标系内复合，与模组渲染矩阵顺序一致。关闭 `face_camera` 或执行“强制刷新”会重新构建图元并清除临时摄像机旋转。导出前请执行“验证资源包”。完整使用说明、字段兼容说明和测试报告随源码项目提供。

“光环属性”面板显示当前定义完整对象树中的图元总数，场景发生新增、删除、复制、迁移或 Mesh 转换后会实时重新统计。

组与图元支持同父级批量复制、删除和移动。在“大纲视图”或 3D 视图中多选同一直接父级下的 Halo 部件即可；复制/删除允许组与图元混选，移动时需按类型分别选择。多个组直接一起重设父级，多个图元则一起迁移到一个新的属性副本组。跨父级、跨定义或夹杂普通对象的选择会整体拒绝。

`face_camera` 在动画播放期间持续生效：扩展会记住最近一次 3D 视图朝向，并在每帧父组动画求值后重新应用图元朝向。

选择目标 Halo 父级后，“Mesh 转子组”可从当前场景 Collection 选择普通 Mesh：扩展以源网格局部坐标建立默认变换包装组，为每个有效面簇计算最小覆盖矩形，创建扁平子组和 Billboard，并将材质转换为透明 PNG。同材质、同朝向、共面且共享边的面默认合并，消除内部接缝；可配置 0–64 圈边缘扩张，扩张像素精确复制邻近采样 RGBA，不平均颜色。“直接 UV 采样”默认关闭；开启后简单的纯色或直接 Image Texture 材质绕过 Cycles，复杂节点自动回退烘焙。交互转换逐面簇运行，侧栏提供进度条和取消按钮。生成贴图打包在 `.blend` 中，并只在导出时写入资源包，不修改导入源包。
